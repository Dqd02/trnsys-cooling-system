## 1. `TankOutletOK = le([7,1],5.0)` 到底是什么意思

TRNSYS Equation 中：

```text
le(a,b)
```

表示 `a <= b` 时输出 `1`，否则输出 `0`。所以：

```text
TankOutletOK = le([7,1],5.0)
```

准确含义是：

- `[7,1] <= 5.0 degC`：`TankOutletOK=1`，水箱出水温度合格，**允许使用**；
- `[7,1] > 5.0 degC`：`TankOutletOK=0`，水箱出水温度偏高，**不允许继续独立供冷**。

因此，它不是“小于 5 degC 不能用”，而是“小于等于 5 degC 才能用”。

您没有把这条公式加入控制，可以继续采用纯 SOC/节点温度判断。两种方案的权衡为：

- 不加 `TankOutletOK`：控制更简单，完全沿用第 6.3 节的 SOC/空罐和流量能力逻辑；但可能出现平均 SOC 尚可、实际出水已经升温，仍继续释冷的情况。
- 加 `TankOutletOK`：更能保证供水品质，但阈值附近可能频繁切换，最好配合死区或锁存。

本报告以下建议尊重您的选择，**不加入 `TankOutletOK`**。

但要准确表述：在不检查实时出水温度、也不直接计算剩余可用冷量的情况下，`TankCanCover=Dch_bySOC*TankFlowOK` 只表示“水箱尚未被判空，并且释冷泵的瞬时流量能力足够”，不能严格证明水箱实际可输出冷量一定覆盖当前负荷。若用于论文，建议将变量改名为 `TankAllowed`；若继续保留 `TankCanCover`，应在方法中说明它是控制许可判据，不是独立的能量平衡证明。

## 4. 最小修改方案：保持当前泵接线名称

如果您不想在 Studio 中重新连接 Unit49-56，只修改 Unit34 Equation，最小改法如下。

### 4.1 替换4条公式

把：

```text
DischargePump_ON = TankMode
CondPump1_ON = Chiller1_ON
CondPump2_ON = Chiller2_ON
IsLoadTime = ge(HourOfDay,8)*le(HourOfDay,22)
```

改成：

```text
DischargePump_ON = DCHP_CTRL
CWPump1_CTRL = CHWP1_CTRL
CWPump2_CTRL = CHWP2_CTRL
IsLoadTime = ge(HourOfDay,8)*lt(HourOfDay,22)
```

然后在 Studio 中仍必须把四台冷却泵的第3输入从非法的旧变量改为：

```text
Unit53、Unit55 -> CWPump1_CTRL
Unit54、Unit56 -> CWPump2_CTRL
```

原因是 `CondPump...` 变量名本身非法，不能通过保留接线完全解决。

### 4.2 删除1条无效公式

删除：

```text
ReturnPump_ON = TankMode + 0.5*ChillerMode
```

当前没有任何回水泵模块使用该信号。

### 4.3 增补2条冷却泵计算式

在 `CHWP1_CTRL/CHWP2_CTRL` 之后增加：

```text
CWPump1_CTRL = CHWP1_CTRL
CWPump2_CTRL = CHWP2_CTRL
```

这样 Equation 总数从当前52条变为：

```text
52 - 1 + 2 = 53条
```

其中只是把3条旧公式替换，不影响数量；删除 `ReturnPump_ON` 减1，增加两条冷却泵连续信号加2。

## 7. 最终判断

### 正确的控制

- 冷机1、冷机2：`max(ChargeMode,ChillerMode)`，正确。
- 供冷泵1、供冷泵2：当前通过 `CHWPump*_ON=CHWP*_CTRL` 获得连续信号，正确。
- 蓄冷泵：夜间蓄冷时固定信号1，正确。
- 冷却塔1、冷却塔2：与对应冷机0/1联锁，正确。
- Gamma14、Gamma24、Gamma29：公式方向正确；需要更新过时注释。

### 不正确的控制

- Unit49 释冷泵仍使用 `TankMode` 的0/1信号，没有按105%需求流量变频。
- Unit53-56 冷却泵仍使用0/1信号，没有跟随对应供冷泵的连续信号。
- `CondPump1_ON/2_ON` 是TRNSYS非法变量名。
- `ReturnPump_ON` 没有实际设备使用。
- `IsLoadTime` 使用 `le(...,22)`，多包含了22:00-22:15一个时步。

建议采用第5节直接重连方案。它与原第6.3节一致，变量名称也能直接反映“连续控制”与“二值启停”的区别。

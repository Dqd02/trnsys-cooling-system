## 2. 冷水机组参数审查

### 2.1 制冷量选型

**基载冷机（2×1400 kW）：**

* 建筑 9-22 稳态最大负荷：3,025 kW
* 建筑 9-22 稳态 P95 负荷：2,741 kW
* 2×1400 = 2,800 kW 接近 P95 稳态，大部分时间可独立承担
* 极端日（3,025 kW）需水箱补冷 225 kW，设计合理

**蓄冷机组（1×3000 kW）：**

* 水箱有效蓄冷量约 17,577 kWh（见第 4 节）
* 按 3000 kW 满功率蓄冷：17,577 ÷ 3,000 ≈ **5.87 h**
* 夜间谷电 8h 窗口充裕，蓄冷时间绰绰有余
* **结论：制冷量选型合理**

### 2.2 冷冻水流量校核

系统设计供回水温度 4/12°C，ΔT = 8 K。

| **冷机** | **额定冷量 (kW)** | **设计温差 (K)** | **理论流量 (kg/s)** | **理论流量 (kg/hr)** | **实际设定 (kg/hr)** | **偏差**   |
| ------ | ------------- | ------------ | --------------- | ---------------- | ---------------- | -------- |
| 基载冷机   | 1,400         | 8            | 41.75           | 150,300          | 150,300          | **0%** ✓ |
| 蓄冷机组   | 3,000         | 8            | 89.50           | 322,200          | 322,200          | **0%** ✓ |

验证：Q = m × Cp × ΔT

* 基载：41.75 × 4.19 × 8 = 1,400 kW ✓
* 蓄冷：89.50 × 4.19 × 8 = 3,000 kW ✓

**结论：冷冻水流量参数完全匹配 ΔT=8K 设计。无问题。**

### 2.3 冷却水流量校核

| **冷机** | **冷量 (kW)** | **COP** | **排热量 (kW)** | **冷却水 ΔT (K)** | **理论 CW 流量 (kg/hr)** | **泵设定 (kg/hr)** | **偏差** |
| ------ | ----------- | ------- | ------------ | -------------- | -------------------- | --------------- | ------ |
| 基载     | 1,400       | 6.147   | 1,628        | 5.0            | 279,800              | 279,800 ✓       | 0%     |
| 蓄冷     | 3,000       | 6.147   | 3,488        | 5.0            | 599,100              | 599,100 ✓       | 0%     |

排热量 = 冷量 × (1 + 1/COP)

* 基载：1,400 × (1 + 1/6.147) = 1,628 kW
* 蓄冷：3,000 × (1 + 1/6.147) = 3,488 kW

CW 温升 = 排热量 ÷ (流量 × Cp) = 5.0 K（从 30°C → 35°C）

⚠️ **注意**：冷机 1/2 的初始 CW 流量写为 220,000 kg/hr，但实际运行时上游冷却水泵（279,800 kg/hr）会强制驱动流量，初始值只影响第一个时间步。建议初始值改为与泵匹配以避免启动瞬态异常。

**结论：冷却水流量匹配合理。初始值偏差不影响稳态运行。**

### 2.4 冷机性能数据 —— **关键问题**

三台冷机（Unit 9, 12, 35）使用**完全相同的**性能数据文件，Samp\_C1/C2/C3.Dat 内容一致，PLR 文件也一致。

性能数据的额定点：**CHWT = 7°C, CWT = 30°C** 时 capacity ratio = 1.0, COP ratio = 1.0。

**问题：蓄冷机组出 4°C 水，不在 7°C 的额定点工作。**

从性能数据查表（CHWT=4°C, CWT=30°C）：

| **参数**         | **额定点 (7/30°C)** | **蓄冷工况 (4/30°C)** | **衰减**    |
| -------------- | ---------------- | ----------------- | --------- |
| Capacity Ratio | 1.0000           | **0.9334**        | **-6.7%** |
| COP Ratio      | 1.0000           | **0.9394**        | **-6.1%** |
| 实际冷量 (kW)      | 3,000            | **2,800**         | -200 kW   |
| 实际 COP         | 6.147            | **5.77**          | -0.38     |

**蓄冷机组在 4°C 出水时，真正可用容量只有约 2,800 kW，而非铭牌标的 3,000 kW。** 如果控制系统按 3,000 kW 负荷调度蓄冷机组，机组会频繁启停或超载保护。

**建议：**

1. 确认蓄冷机组的**出厂额定工况是 4°C 出水还是 7°C 出水**。若为 4°C 出水，应使用 4°C 额定点的性能文件。
2. 若维持 7°C 额定的通用性能曲线，应将蓄冷机组额定容量从 10,800,000 提至 **11,570,000 kJ/hr（≈3,214 kW）**，确保 4°C 出水时实得有 3,000 kW。

### 2.5 PLR 部分负荷曲线

三台冷机共用同一 PLR 曲线：

| **PLR** | **0.00** | **0.25** | **0.50** | **0.75** | **1.00** |
| ------- | -------- | -------- | -------- | -------- | -------- |
| 功率比     | 0.0000   | 0.2497   | 0.4956   | 0.6902   | 1.0000   |

该曲线在 PLR=0.75 时功率比为 0.6902，呈轻微上凸（部分负荷下比线性更节能）。符合标准离心式/螺杆式冷水机组特征，**参数合理**。

### 3.2 冷却塔热工校核

| **项目**                | **冷却塔 1/2** | **冷却塔 3**   |
| --------------------- | ----------- | ----------- |
| 设计散热量                 | 1,810 kW    | 3,876 kW    |
| 实际排热量                 | 1,628 kW    | 3,488 kW    |
| Design Range (温差)     | 5.56 K      | 5.56 K      |
| Design Approach (逼近度) | 2.44 K      | 2.44 K      |
| **气水比**               | **1.07** ✓  | **0.50** 🔴 |

**冷却塔 3 气水比仅 0.50，严重偏小。** 常规机械通风冷却塔设计气水比应在 0.8-1.5 之间。气水比过低意味着风量不足以带走设计排热量，出水温度将高于设计值，导致冷机冷凝温度升高、COP 下降。

### 3.3 风扇功率合理性 —— **核心问题**

三台冷却塔的风扇功率完全相等（30.33 kW），但热负荷相差 2.14 倍。这在物理上不可行。

工程经验参考：

| **散热量范围**  | **典型比功率**             | **预期风扇功率**     |
| ---------- | --------------------- | -------------- |
| \~1,800 kW | 0.03-0.05 kW/kW\_heat | **54-90 kW**   |
| \~3,900 kW | 0.03-0.05 kW/kW\_heat | **117-195 kW** |

当前 30.33 kW 对应比功率 = 30.33/1810 = **0.017 kW/kW\_heat**，远低于行业常规（高效轴流风机极少低于 0.025）。

### 3.4 风速与风量参数 —— **需重新设定**

Type126 无独立风速输入，风量通过以下参数体现：

* **Design Air Flow Rate（参数 6）**：设计工况风量
* **Natural Convection Airflow Fraction（参数 8）**：自然对流风量比例，当前 0.2
* **Natural Convection Capacity Fraction（参数 9）**：自然对流能力比例，当前 0.1

当前参数 8/9 是 TRNSYS 默认值，缺少工程依据。实际冷却塔风扇不转时自然通风能力远低于此。

**建议修改：**

| **参数**                | **冷却塔 1/2**                            | **冷却塔 3**                                | **说明**        |
| --------------------- | -------------------------------------- | ---------------------------------------- | ------------- |
| Design Air Flow Rate  | → **350,000-420,000** kg/hr            | → **600,000-900,000** kg/hr              | 气水比 1.0-1.5   |
| Fan Power at Design   | → **195,000-325,000** kJ/hr (54-90 kW) | → **420,000-700,000** kJ/hr (117-195 kW) | 比功率 0.03-0.05 |
| Natural Conv Airflow  | 0.2 → **0.05**                         | 0.2 → **0.05**                           | 更接近实际         |
| Natural Conv Capacity | 0.1 → **0.03**                         | 0.1 → **0.03**                           | 更接近实际         |

**市场参考**：散热量 1,800 kW 级开式冷却塔（良机/BAC/益美高），风机功率通常 55-75 kW；3,900 kW 级通常 130-180 kW。

**结论：水箱容积与蓄冷量合理。**

### 4.2 散热系数 —— **问题**

```
Tank Loss Coefficient = 0 kJ/hr·m²·K
```

设置为零表示水箱完全绝热。实际水蓄冷罐即使有良好保温，仍存在散热损失。

按直径约 13.4 m（从 2100 m³/15m 推算）、外表面积约 910 m²、保温 U=0.3 W/m²·K（约 100mm 聚氨酯）估算：

* 夏季罐内外温差 \~20 K
* 散热损失 ≈ 910 × 0.3 × 20 = 5,460 W ≈ 19,656 kJ/hr
* 日散热量 ≈ 131 kWh，占日蓄冷量约 0.7%

绝对值不大，但精细化仿真应设为非零：

| **保温等级**        | **对应 U 值 (kJ/hr·m²·K)** | **推荐设置**    |
| --------------- | ----------------------- | ----------- |
| 标准保温 (100mm PU) | \~1.08                  | **1.0-1.5** |
| 加强保温 (150mm PU) | \~0.72                  | **0.7-1.0** |

**建议：将散热系数从 0 改为 1.0-1.5 kJ/hr·m²·K。**

### 4.3 节点数与端口

25 节点（每节点 0.6 m），分层分辨率合理。两个端口均为固定位置（底部进水、顶部出水），适合蓄/释冷交替运行。

**结论：节点数和端口配置合理。**

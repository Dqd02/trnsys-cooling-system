# 南一楼四热区温湿度控制问题与修改步骤

## 1. 当前现象

目标：

```text
南一楼 4 个热区稳定在：
室温 26 C
相对湿度 60%
```

当前运行结果显示，南一楼 4 个热区没有明显受控。`Untitled_imported.plt` 中温度曾达到：

| 热区 | 最高温度约值 | 说明 |
|---|---:|---|
| S_bgs1 办公室 | 35.47 C | 明显高于 26 C |
| S_hys1 会议室 | 36.99 C | 明显高于 26 C |
| S_cs1 卫生间/厕所 | 31.70 C | 明显高于 26 C |
| S_zl1 走廊 | 32.35 C | 明显高于 26 C |

这说明问题不是单纯“设定温度不对”，而是中央空调系统的冷量和除湿量没有有效送进 Type56 的 4 个热区。

## 2. 主要问题点

### 2.1 Type655 冷机水流量未正确接入

Type655 风冷冷水机组要满足以下条件才会制冷：

```text
冷冻水流量 > 0
回水温度 > 出水设定温度
控制信号 gamma >= 0.5
```

之前 Type655 的 `Chilled Water Flowrate` 仍是未连接或没有被有效驱动，导致冷机即使有控制信号，也可能没有实际冷冻水流量。

正确做法：

```text
Type655 input 1: T_return_floor
Type655 input 2: m_chiller
Type655 input 3: 7
Type655 input 4: Type15 室外干球温度
Type655 input 5: Chiller_on
```

### 2.2 Type996 风机盘管水流量未正确接入

4 个 Type996 末端之前的 `Fluid Flowrate` 没有真正接到楼层水流控制变量。

Type996 的制冷条件是：

```text
Gamma_Cool >= 0.5
Flow_Fluid > 0
Gamma_Fan > 0
```

如果冷冻水流量为 0，Type996 不会产生有效制冷量。

正确做法：

```text
办公室 Type996 input 2 -> m_bgs
会议室 Type996 input 2 -> m_hys
厕所 Type996 input 2 -> m_cs
走廊 Type996 input 2 -> m_zl
```

### 2.3 会议室、厕所、走廊控制信号未接上

之前只有办公室 `cool_bgs` 接入了 Type996 的 `Cooling Control Signal` 和 `Fan Control Signal`，其他 3 个热区仍可能是 0。

正确做法：

```text
Type996 hys input 13 -> cool_hys
Type996 hys input 14 -> cool_hys

Type996 cs input 13 -> cool_cs
Type996 cs input 14 -> cool_cs

Type996 zl input 13 -> cool_zl
Type996 zl input 14 -> cool_zl
```

### 2.4 水流量控制逻辑反了

之前 Equa-3 中曾使用：

```text
m_bgs = [30,2] * cool_bgs
m_hys = [35,2] * cool_hys
m_cs  = [36,2] * cool_cs
m_zl  = [37,2] * cool_zl
```

但 `[30,2]`、`[35,2]` 等本身就是 Type996 的水流量输出。如果 Type996 输入流量还没有被设定，输出流量自然为 0，这会形成逻辑死锁：

```text
没有输入水流量
-> Type996 输出水流量为 0
-> Equation 计算 m_bgs 仍为 0
-> Type996 继续没有水流量
```

正确做法是按额定水流量乘控制信号：

```text
m_bgs = 25260 * cool_bgs
m_hys = 12544 * cool_hys
m_cs  = 6014  * cool_cs
m_zl  = 10482 * cool_zl
```

### 2.5 空气混合误用了水流量

Type56 的送风混合应使用空气质量流量。Type996 的关键输出为：

```text
[30,3] = 出风温度
[30,4] = 出风含湿量
[30,6] = 干空气质量流量
```

之前送风混合公式里用了 `[30,2]`，这是水流量，不是空气流量。这样会导致送风温度和含湿量计算失真。

错误逻辑示例：

```text
T_bgs1 = ([30,3]*[30,2] + [32,6]*[32,3]) / ...
```

正确逻辑：

```text
T_bgs1 =
([30,3]*[30,6] + [32,3]*m_oa_bgs1)
/ max(0.01,[30,6]+m_oa_bgs1)

W_bgs1 =
([30,4]*[30,6] + [32,4]*m_oa_bgs1)
/ max(0.01,[30,6]+m_oa_bgs1)
```

### 2.6 Type508 新风盘管没有明确承担除湿目标

上海夏季湿热，如果只靠 Type996 末端冷却，很难稳定把室内 RH 控制到 60%。新风必须先除湿。

建议 Type508 改为含湿量控制：

```text
Mode_Control = 2
W_Air_Want = 0.0095 kg/kg
```

原因：

```text
26 C、60%RH 对应室内含湿量约 0.0126 kg/kg
新风出风设为 0.0090-0.0100 kg/kg
可以给室内人员湿负荷和渗透湿负荷留出除湿余量
```

### 2.7 目前只看温度输出，不足以判断 60%RH 目标

`Untitled_imported.plt` 当前主要输出南一楼 4 个热区温度。要判断 60%RH 是否达成，必须额外输出：

```text
RELHUM_S_bgs1
RELHUM_S_hys1
RELHUM_S_cs1
RELHUM_S_zl1

ABSHUM_S_bgs1
ABSHUM_S_hys1
ABSHUM_S_cs1
ABSHUM_S_zl1
```

## 3. 推荐修改后的 Equa-3 逻辑

建议先用硬开关控制，确认系统能制冷后，再改成 Type2b 滞回控制。

```text
EQUATIONS 36
ACH_bgs1 = ([30,6]+m_oa_bgs1)/(1.2*V_BGS)
V_BGS = 800*4.9
V_HYS = 400*4.9
V_CS = 99.2*4.9
V_ZL = 300.034*4.9

cool_bgs = [38,1]*GT([56,103],26.2)
cool_hys = [38,1]*GT([56,104],26.2)
cool_cs = [38,1]*GT([56,105],26.2)
cool_zl = [38,1]*GT([56,106],26.2)

ACH_hys1 = ([35,6]+m_oa_hys1)/(1.2*V_HYS)
ACH_cs1 = ([36,6])/(1.2*V_CS)
ACH_zl1 = ([37,6]+m_oa_zl1)/(1.2*V_ZL)

Chiller_on = max(max(cool_zl,cool_hys),max(cool_bgs,cool_cs))

T_return_floor =
(m_bgs*[30,1]+m_hys*[35,1]+m_cs*[36,1]+m_zl*[37,1]+m_oa*[32,1]+m_bypass*[25,1])
/ max(0.01,m_chiller)

m_bgs = 25260*cool_bgs
m_hys = 12544*cool_hys
m_cs = 6014*cool_cs
m_zl = 10482*cool_zl
m_oa = 4000*[38,1]

m_load = m_bgs+m_hys+m_cs+m_zl+m_oa
m_min = 0.3*51600
m_chiller = Chiller_on*max(m_load,m_min)
m_bypass = max(0,m_chiller-m_load)

m_oa_air_fan = 1200*3.6*1.2*[38,1]
m_oa_bypass = 0.10

m_oa_bgs1 = 0.60*[32,6]
m_oa_hys1 = 0.25*[32,6]
m_oa_zl1 = 0.15*[32,6]

T_bgs1 = ([30,3]*[30,6] + [32,3]*m_oa_bgs1)/max(0.01,[30,6]+m_oa_bgs1)
T_hys1 = ([35,3]*[35,6] + [32,3]*m_oa_hys1)/max(0.01,[35,6]+m_oa_hys1)
T_cs1 = [36,3]
T_zl1 = ([37,3]*[37,6] + [32,3]*m_oa_zl1)/max(0.01,[37,6]+m_oa_zl1)

W_bgs1 = ([30,4]*[30,6] + [32,4]*m_oa_bgs1)/max(0.01,[30,6]+m_oa_bgs1)
W_hys1 = ([35,4]*[35,6] + [32,4]*m_oa_hys1)/max(0.01,[35,6]+m_oa_hys1)
W_cs1 = [36,4]
W_zl1 = ([37,4]*[37,6] + [32,4]*m_oa_zl1)/max(0.01,[37,6]+m_oa_zl1)
```

## 4. 具体连线修改步骤

### 步骤 1：修改 Type655

Type655 输入应为：

| 输入号 | 变量 | 建议连接 |
|---:|---|---|
| 1 | Chilled Water Inlet Temperature | `T_return_floor` |
| 2 | Chilled Water Flowrate | `m_chiller` |
| 3 | Set Point Temperature | `7` |
| 4 | Ambient Temperature | Type15 干球温度 |
| 5 | Chiller Control Signal | `Chiller_on` |

检查目标：

```text
[25,1] 出水温度应接近 7 C
[25,2] 冷冻水流量应 > 0
[25,3] 冷机功率应 > 0
[25,5] COP 应 > 0
[25,7] 实际供冷量应 > 0
```

### 步骤 2：修改 4 个 Type996 水流量和控制信号

办公室：

```text
Type996 bgs input 2  -> m_bgs
Type996 bgs input 13 -> cool_bgs
Type996 bgs input 14 -> cool_bgs
```

会议室：

```text
Type996 hys input 2  -> m_hys
Type996 hys input 13 -> cool_hys
Type996 hys input 14 -> cool_hys
```

厕所：

```text
Type996 cs input 2  -> m_cs
Type996 cs input 13 -> cool_cs
Type996 cs input 14 -> cool_cs
```

走廊：

```text
Type996 zl input 2  -> m_zl
Type996 zl input 13 -> cool_zl
Type996 zl input 14 -> cool_zl
```

检查目标：

```text
[30,8], [35,8], [36,8], [37,8] 总冷量应 > 0
[30,9], [35,9], [36,9], [37,9] 显冷量应 > 0
[30,6], [35,6], [36,6], [37,6] 空气流量应 > 0
[30,3], [35,3], [36,3], [37,3] 出风温度应低于对应回风温度
```

### 步骤 3：修改 Type146 新风机

Type146 输入建议：

| 输入号 | 变量 | 建议连接 |
|---:|---|---|
| 1 | Inlet Air Temperature | Type15 干球温度 |
| 2 | Inlet Air Humidity Ratio | Type15 含湿量 |
| 3 | Inlet Air RH | Type15 RH |
| 4 | Air Flow Rate | `m_oa_air_fan` |
| 5 | Inlet Air Pressure | `1` |
| 6 | Control Signal | 工作时间表 `[38,1]` |
| 7 | Pressure Increase | `0` |

`m_oa_air_fan` 建议：

```text
m_oa_air_fan = 1200*3.6*1.2*[38,1]
```

其中：

```text
1200 L/s = 单层初始新风量
3.6 = L/s 转 m3/h 的系数
1.2 kg/m3 = 空气密度近似值
```

### 步骤 4：修改 Type508 新风盘管

建议把 Type508 从 free-floating 改为含湿量控制：

```text
Mode_Control = 2
Mode_Humidity = 2
Cp_Fluid = 4.190
```

输入建议：

| 输入号 | 变量 | 建议连接 |
|---:|---|---|
| 1 | Fluid Inlet Temperature | Type655 出水温度 `[25,1]` |
| 2 | Fluid Flowrate | `m_oa` |
| 3 | Air Inlet Temperature | Type146 出口温度 `[31,1]` |
| 4 | Air Inlet Humidity Ratio | Type146 出口含湿量 `[31,2]` |
| 5 | Air Inlet RH | Type146 出口 RH `[31,3]` |
| 6 | Air Flowrate | Type146 出口流量 `[31,4]` |
| 7 | Air Pressure | Type146 出口压力 `[31,5]` |
| 8 | Air-Side Pressure Drop | `0` |
| 9 | Coil Bypass Fraction | `m_oa_bypass` |
| 10 | Target outlet humidity ratio | `0.0095` |

调参范围：

```text
如果室内 RH > 60%：W_Air_Want 降到 0.0085-0.0090
如果室内 RH < 50%：W_Air_Want 升到 0.0105-0.0110
```

### 步骤 5：修正送风混合

送风混合必须使用空气质量流量：

```text
Type996 空气流量输出 = [Type996,6]
Type508 空气流量输出 = [32,6]
```

不要用：

```text
[30,2], [35,2], [36,2], [37,2]
```

因为这些是水流量。

## 5. 调试顺序

### 第 1 轮：确认冷机启动

输出：

```text
[25,1] Type655 出水温度
[25,2] Type655 冷冻水流量
[25,3] Type655 功率
[25,5] Type655 COP
[25,7] Type655 实际供冷量
[25,8] Type655 PLR
```

判断：

```text
若 [25,2] = 0，说明 m_chiller 没接上或 Chiller_on 为 0
若 [25,1] 不接近 7 C，说明冷机没有真正运行或负荷/流量逻辑仍有问题
```

### 第 2 轮：确认末端制冷

输出：

```text
[30,8], [35,8], [36,8], [37,8] 总冷量
[30,9], [35,9], [36,9], [37,9] 显冷量
[30,3], [35,3], [36,3], [37,3] 出风温度
[30,6], [35,6], [36,6], [37,6] 空气流量
```

判断：

```text
若总冷量仍为 0，检查 Type996 input 2/13/14
若空气流量为 0，检查 Fan Control Signal
若出风温度高于回风温度，检查冷冻水入口温度和水流量
```

### 第 3 轮：确认 Type56 收到送风

输出：

```text
T_bgs1, W_bgs1, ACH_bgs1
T_hys1, W_hys1, ACH_hys1
T_cs1,  W_cs1,  ACH_cs1
T_zl1,  W_zl1,  ACH_zl1
```

判断：

```text
T_* 应低于区内空气温度
W_* 应低于或接近目标含湿量
ACH_* 应大于 0
```

### 第 4 轮：确认室温和湿度目标

输出：

```text
[56,103] TAIR_S_bgs1
[56,104] TAIR_S_hys1
[56,105] TAIR_S_cs1
[56,106] TAIR_S_zl1

[56,107] RELHUM_S_bgs1
[56,108] RELHUM_S_hys1
[56,109] RELHUM_S_cs1
[56,110] RELHUM_S_zl1

[56,111] ABSHUM_S_bgs1
[56,112] ABSHUM_S_hys1
[56,113] ABSHUM_S_cs1
[56,114] ABSHUM_S_zl1
```

判断：

```text
温度应逐步靠近 26 C
RH 应逐步靠近 60%
ABSHUM 在 26 C、60%RH 附近约为 0.0126 kg/kg
```

## 6. 后续调参建议

### 6.1 温度仍高于 26 C

按顺序检查：

1. Type655 出水是否约 7 C。
2. Type996 总冷量是否大于对应热区负荷。
3. Type56 是否仍有未关闭的重复 ventilation 或 ideal cooling 干扰判断。
4. 送风 ACH 是否太低。
5. 末端额定冷量是否偏小。

可调参数：

```text
提高 Type996 额定水流量
提高 Type996 额定风量
降低冷冻水供水温度到 6 C
扩大控制开启阈值，例如 T > 26.0 即开
```

### 6.2 温度低于 26 C 或波动大

硬开关只是调试用，确认系统有效后应改为滞回：

```text
办公室/会议室：
T_on = 26.5 C
T_off = 25.8 C

厕所/走廊：
T_on = 26.8-27.0 C
T_off = 26.0-26.3 C
```

### 6.3 RH 高于 60%

优先处理新风盘管：

```text
Type508 W_Air_Want = 0.0085-0.0090 kg/kg
增加 m_oa
检查 Type508 冷冻水流量 m_oa 是否 > 0
检查 Type508 出风含湿量 [32,4] 是否低于室内 ABSHUM
```

### 6.4 RH 低于 50%

说明除湿过强：

```text
Type508 W_Air_Want 提高到 0.0105-0.0110 kg/kg
减少新风盘管水流量 m_oa
减少新风量
```

## 7. 重要提醒

1. 现在先用硬开关控制，是为了验证冷量是否能送进 Type56；不是最终控制策略。
2. 最终应恢复 Type2b 滞回控制，避免频繁启停。
3. 60%RH 不能只靠温度控制实现，必须输出并校核 RH 与 ABSHUM。
4. Type56 内如果仍保留其他楼层的 `COOLING = COOL001`，全楼总能耗仍不能作为最终系统能耗。
5. 当前只调南一楼，确认稳定后再复制到其他楼层。

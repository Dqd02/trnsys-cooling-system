# 上海研发办公楼水蓄冷系统可行性评估整改版

## 1. 整改结论

上一版把“蓄冷量覆盖 75% 日冷量”作为目标，这是不合适的。蓄冷率不是固定标准值，而应由负荷曲线、峰谷电价、设备增量投资、机房和水箱条件、冷机低温工况效率、运行策略共同优化得出。

对本项目，若仍按 75% 日冷量配置，水箱会达到约 3,300-3,500 m3，夜间低温制冷能力也要放大到约 3.2-3.4 MW。这已经接近“高比例蓄冷/准全量蓄冷”的工程特征，不适合作为一栋约 1.92 万 m2 研发办公楼的优先推荐方案。

整改后的建议是：采用**削峰型部分水蓄冷**，以白天削减高峰负荷、提高冷机运行稳定性、降低白天高价电消耗为目标，而不是追求固定蓄冷率。

推荐方案：

- 水箱有效容积：**1,000-1,200 m3**。
- 推荐基准值：**1,100 m3**。
- 4/12°C 水系统，计算温差 **8 K**。
- 分层水箱有效利用率按 **0.90**。
- 推荐基准蓄冷量：**约 9,211 kWh**。
- 对平均正常日的蓄冷率：**约 35%**。
- 对 P95 高温日的蓄冷率：**约 27%**。
- 对最大日的蓄冷率：**约 25%**。

这一区间更符合“部分蓄冷”的工程逻辑：水箱不过度放大，夜间蓄冷可在 0:00-8:00 内从容完成，白天仍保留冷水机组作为基载和补冷。

## 3. 4/12°C 与 10K 温差的含义

你设定的“制冷 4°C、回水 12°C”，对应水箱可用温差：

```text
ΔT = 12 - 4 = 8 K
```

工程上常见的“水箱温差 10°C”只是初设估算口径，通常表示水箱冷端和热端之间可利用 10K 温差，例如 4/14°C、5/15°C 等。它不是强制标准值。

本项目若末端和板换侧回水只能稳定到 12°C，则应按 **8K** 计算。直接套用 10K 会低估水箱容积约 20%。若要实现 10K，要么把回水温度提高到约 14°C，要么进一步降低供水温度；前者要求末端盘管和控制策略匹配，后者会增加低温制冷效率损失和防冻风险。

## 4. 水箱蓄冷量计算

水蓄冷水箱储冷量计算公式：

```text
Q(kWh) = 1.163 × V(m3) × ΔT(K) × η
```

其中：

- `1.163 kWh/(m3·K)` 为水的体积比热折算值。
- `V` 为水箱有效容积。
- `ΔT=8K`，来自 4/12°C。
- `η=0.90`，表示分层水箱有效利用率。

因此，单位水箱有效容积储冷量为：

```text
1.163 × 8 × 0.90 = 8.37 kWh/m3
```

推荐基准水箱 1,100 m3 时：

```text
Q = 1.163 × 1,100 × 8 × 0.90
  = 9,211 kWh
```

- 相对平均正常日：**35.2%**。
- 相对 P95 高温日：**26.7%**。

## 7. 整改后的设备配置建议

### 方案 A：经济保守型

| 项目 | 建议 |
|---|---|
| 冷水机组 | 2×1,000 kW，或 2×1,100 kW |
| 水箱有效容积 | 900-1,000 m3 |
| 蓄冷量 | 7,536-8,374 kWh |
| 平均正常日蓄冷率 | 28.8%-32.0% |
| 特点 | 投资和占地较低，削峰能力适中 |

### 方案 B：推荐平衡型

| 项目 | 建议 |
|---|---|
| 冷水机组 | 2×1,100 kW，低温 4°C 蓄冷工况需厂家复核 |
| 水箱有效容积 | 1,100-1,200 m3 |
| 蓄冷量 | 9,211-10,048 kWh |
| 平均正常日蓄冷率 | 35.2%-38.4% |
| P95 高温日蓄冷率 | 26.7%-29.1% |
| 特点 | 削峰效果、夜间蓄冷时长、水箱规模较均衡 |

### 方案 C：偏稳健型

| 项目 | 建议 |
|---|---|
| 冷水机组 | 2×1,200 kW，或 3×800 kW |
| 水箱有效容积 | 1,300-1,500 m3 |
| 蓄冷量 | 10,886-12,560 kWh |
| 平均正常日蓄冷率 | 41.6%-48.0% |
| 特点 | 高温日削峰更强，但水箱和增量投资明显增加 |

综合推荐 **方案 B**。它不会被 75% 蓄冷率误导，也不会把系统做成接近全量蓄冷；同时对 8:15 开机尖峰和下午高负荷时段有足够削峰能力。

## 8. 运行策略

夜间 0:00-8:00：按次日预测负荷蓄冷。推荐基准 1,100 m3 对应约 9.2 MWh，若低温蓄冷工况可用制冷量按 1.6-1.8 MW 估算，约 5-6 小时可蓄满，不要求 0-8 点全时满负荷运行。

8:00-9:00：水箱预放冷，冷机不追随 8:15 瞬时尖峰。末端采用缓启动和供水温度斜坡控制，将建筑夜间蓄热拉降过程摊平。

9:00-18:00：冷水机组承担稳定基载，水箱承担超过基载的高峰差额。推荐以 2,000-2,200 kW 作为白天冷机基载控制区间。

18:00-22:00：负荷回落后减少放冷强度，保留水箱余量应对晚间会议、人员滞留或气象偏差。

## 9. 经济红线的处理方式

你提到“相对于常规系统的增量投资，静态回收期宜小于 5 年”，这个判断方向合理，但目前缺少上海项目的实际电价合同、设备报价、土建条件、机房/水箱位置和运维策略，不能给出真实回收期。

可用的约束方式是：

```text
允许的最大增量投资 ≈ 年净节省费用 × 5
```

其中年净节省费用应扣除：

- 夜间蓄冷转移的电费收益。
- 4°C 低温蓄冷导致的 COP 下降损失。
- 蓄冷泵、放冷泵、板换压降和控制系统附加能耗。
- 水箱、阀组、板换和自控系统维护费用。

在没有报价和电价合同前，不建议把水箱推到 1,500 m3 以上。**1,100-1,200 m3** 是更适合进入下一轮技术经济比选的区间。

## 10. 设计注意事项

- 冷水机组选型必须同时校核标准供冷工况和 4°C 低温蓄冷工况，不能只看 7/12°C 名义制冷量。
- 4°C 出水对防冻保护、板换端差、阀门调节和末端盘管除湿能力提出更高要求，建议设置低温保护和最小流量保护。
- 水箱宜采用分层水箱，上下布水器需要按低流速均匀布水设计，避免短路和混层。
- 8:15 尖峰应作为控制策略和水箱瞬时放冷能力校核项，不宜直接放大为冷机名义容量。
- 后续应以 900、1,100、1,300 m3 三档做电费收益和增量投资敏感性分析，再确定最终施工图容量。

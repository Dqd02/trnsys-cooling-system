## 3. 早晨8:15开机尖峰特征

### 3.1 尖峰数值

| 指标 | 数值 |
|---|---|
| 最大尖峰（8-9段） | **3575 kW**（2026-07-30 08:15，极端热日） |
| 8-9段 P95 | 2625 kW |
| 8-9段工作日均值（含零值） | 351 kW |
| 尖峰出现时刻分布 | 8:00-8:15（40天）、8:15-8:30（52天），合计占全工作日 92% |

### 3.2 尖峰成因

该尖峰**来自 TRNSYS 中 `POWER=999999999` 的理想冷源设置**。8:00 制冷系统启动后，对夜间（22:00-8:00）14h 内建筑蓄积的热量进行集中拉降，理想冷源无容量上限，瞬时释放全部冷量。

实际工程中冷水机组存在额定容量，拉降过程约1-2小时，不会产生真正的3575 kW瞬时尖峰。  
**建筑负荷需求分析保留此尖峰；机组选型和运行策略以9-22稳态为准。**

### 3.3 尖峰量级评价

| 比值 | 数值 | 评价 |
|---|---|---|
| 8:15尖峰 / 9-22稳态中位 | **1.82** | 开机拉降显著，相当于稳态的1.8倍 |
| 8:15尖峰 / 9-22 P95 | **1.30** | 高于95%分位稳态30% |
| 8:15 P95 / 9-22中位 | **1.34** | P95开机段仍高于稳态中位34% |

## 4. 峰谷比分析

### 4.1 日内峰谷（9-22段内）

| 比值类型 | 数值 | 说明 |
|---|---|---|
| **9-22 全段峰值 / 稳态中位** | **1.54** | 3025 / 1964 kW |
| **9-22 P95 / 稳态中位** | **1.40** | 2741 / 1964 kW |
| 下午峰(P50) / 午休谷(P50) | **1.44** | 2191 / 1525 kW，日内午休谷 |
| 上午爬坡谷(9-10 P50) / 上午平台(10-11 P50) | **0.55** | 1163 / 2119 kW，9-10尚未稳定 |

### 4.2 评价

- **9-22段峰/稳 = 1.54，偏高。** 对于部分蓄冷应用，峰/稳比值超过1.4时蓄冷削峰收益明显，超过1.5则运行策略需要精细管理以避免放冷不均匀。
- 午休谷深度约28%（从2100降至1525kW），源于会议室12:00暂停+人员午休；这一谷可在日内蓄/放冷策略中利用（午休期间冷机多制冷蓄入水箱，下午放冷削峰）。
- 9-10过渡段（中位1163 kW）远低于10-22稳态（中位约2000-2190 kW），是**开机后爬坡引发的假谷**，不是真正的低负荷时段，不适合作为蓄冷放冷窗口。

## 6. 蓄冷场景下的削峰策略

> **目标**：将 9-22 段峰值从 3025 kW 降低至约 2500 kW（峰/稳比 1.27），同时允许稳态从 1964 kW 适度下降，但峰/稳比要显著改善。  
> **原则**：不考虑经济问题；优先通过建筑参数、人员、时间表调整实现；不改变供冷时间窗口（8:00-22:00）。

### 6.1 开机尖峰削减（8:00-9:00 → 作用于8:15 spike）

#### 策略1：制冷设定点斜坡启动（首选，改动最小）

**当前**：8:00 制冷系统启动，直接设定 26°C，理想冷源全功率拉降。  
**建议**：将8:00-9:00的制冷设定温度设为**斜坡下降**：

```
8:00  → 设定 30°C（仅轻度制冷）
8:30  → 设定 28°C
9:00  → 达到 26°C
```

在 TRNBuild 中对 `Cooling_workday_8_22` 的 setpoint 由当前的恒定26°C改为时变 Type14 控制，8:00-9:00线性从30降到26°C。这可将开机段的冷量释放速率降低约50-70%，尖峰从3575 kW预期可降至1500-2000 kW，同时夜间蓄热分摊到更长爬坡时间。

#### 策略2：新风预冷提前（配合策略1）

**当前**：办公室/会议室新风 8:30 开启，走廊 9:00 开启。  
**建议**：将**办公室/厕所新风提前至 7:30 开启**，走廊新风提前至 8:30。在建筑进人前引入新鲜空气并开始轻度降温，减少8:00开机时存量蓄热，从根源减小尖峰幅度（预计降低8:15尖峰10-20%）。

#### 策略3：水箱预放冷（蓄冷系统侧）

**当前**：8:00冷机直接供冷拉降。  
**建议**：8:00-9:00期间**水箱优先放冷**，冷机不追随开机瞬时尖峰；等9:00人员到位、负荷进入稳态后冷机再逐步加载。这是蓄冷系统最直接的开机尖峰削减手段，不改变建筑参数即可实现。

---

### 6.2 9-22稳态峰值削减（目标：峰→2500 kW，比例↓18%）

9-22段真正的高峰出现在 **10:00-12:00上午集中使用期** 和 **14:00-16:00下午会议密集期**，两个时段的P95均在2800-2815 kW。

#### 策略4：会议室错峰使用（效果显著）

**当前问题**：12个会议室共用同一 `meeting_time`，每天9:30-12:00和14:00-17:00全部同步使用，形成12个热区同步冲击。  
**建议**：将12个会议室分为**三组（4间/组）**，采用错峰时间表：

| 组别 | 上午会议 | 下午会议 |
|---|---|---|
| A组（1-4楼南侧）| 9:30-11:30 | 13:30-15:30 |
| B组（5-6楼+北侧部分）| 10:00-12:00 | 14:00-16:00 |
| C组（剩余）| 10:30-12:30（或午休后13:30-15:30）| 14:30-16:30 |

错峰后上午会议高峰负荷可分散约30%，从3025 kW预计可降至2400-2600 kW，而对整体日均冷量影响极小（人员总使用时间不变）。

#### 策略5：会议室峰值人数进一步削减

**当前**：`SCALE2 = 60×loss_rate + 100`，即100-160人/400m²，峰值密度2.5 m²/人（极密）。  
**建议**：将上限从160人降至**130-140人**（峰值密度提升至2.9 m²/人，更接近实际会议占用率）：

```
SCALE2 = 40*loss_rate + 100   → 100-140人
```

这不影响会议室的使用时段，仅降低高峰人员密度。预计降低会议室高峰负荷约8-15%。

#### 策略6：设备负荷逐步加载

**当前**：人员、照明、设备通过 `work_sch` 在9:00-9:30从0线性升至1（相当于30min爬坡）。  
**建议**：对**设备负荷单独设置缓慢爬坡**，在9:00-10:00期间从0升至1（延长至60min）。计算机、工作站等设备集中上电是上午10点前负荷陡升的重要原因，延长爬坡可将9-10点的高峰分摊。

在 TRNSYS 中将设备热源（`CONVECTIVE=32, RADIATIVE=28`，即 60 kJ/h·m²）使用独立的 Type14 时间表，与人员/照明解耦，爬坡时间从 0.5h 延长至 1.5h。

预计效果：将9-11点P95从2815降至2600 kW左右（约降8%）。

#### 策略7：照明分区延时开启

**当前**：照明通过 `work_sch` 统一控制，9:00同步点亮全楼。  
**建议**：将南楼和北楼照明分组，设置15-30分钟错开：
- 南楼照明：9:00 开始爬坡
- 北楼照明：9:15 开始爬坡

照明得热11.9 W/m²×9600m²（办公室）= 约114 kW显热，错峰开启可将9-10点冲击峰削减约50-80 kW。

#### 策略8：遮阳提前干预

**当前**：遮阳在辐射强度达到328 W/m² 时才关闭。  
**建议**：在 7:30 后，当辐射强度达到 200 W/m² 时即触发遮阳，减少开机前建筑蓄热积累，从而降低8:00-10:00的拉降负荷峰值。将 `EXT_WINDOW1` 关闭阈值从 1180 kJ/(h·m²) 降至约 **800 kJ/(h·m²) ≈ 222 W/m²**（仅在8:00前后的早晨低角度太阳时段生效），也可通过时段控制（7:00-10:00遮阳优先）实现。

### 6.3 策略组合与效果预期

| 策略组合 | 作用对象 | 峰值目标 | 稳态影响 | 峰/稳改善 |
|---|---|---|---|---|
| 仅策略3（水箱预放冷） | 8:15 尖峰 | 8:15消除 | 无影响 | 8:15 spike→稳态同级 |
| 策略1+2（斜坡+新风提前） | 8:15 尖峰 | 3575→~1800 kW | 9:00稳态不受影响 | 8:00-9:00段大幅平滑 |
| 策略4（会议室错峰） | 9-22峰值 | 3025→~2400 kW | 稳态中位基本不变 | 峰/稳 1.54→~1.22 |
| 策略5+6+7（人数+设备+照明） | 9-22峰值 | 进一步降低约10% | 稳态轻微下降（可接受） | 协同削峰 |
| **推荐组合：策略1+3+4+5** | 8:15+9-22 | **3025→2300-2500 kW** | 稳态1964→~1800-1900 kW | **峰/稳 ~1.25-1.32** |

> 推荐组合后峰/稳比从1.54降至约1.25-1.32，进入部分蓄冷运行策略的舒适区间，水箱放冷均匀性显著改善，冷机不需要追随短时尖峰。

## 7. 给TRNSYS模型的具体参数修改建议

| 修改位置 | 当前值 | 建议值 | 预期效果 |
|---|---|---|---|
| 制冷设定温度8:00-9:00 | 恒定26°C | Type14斜坡：8:00→30°C，9:00→26°C | 开机尖峰降低50%+ |
| 新风开启时间（办公室/厕所） | 8:30 | **7:30** 提前1小时 | 减少蓄热，降低开机冲击 |
| 会议室时间表分组 | 12个同步 | 三组错峰，偏移量30min/组 | 峰值削减15-25% |
| 会议室人员上限 | 160人 → `60*loss_rate+100` | 改为 `40*loss_rate+100`（上限140） | 高峰人员负荷降约12% |
| 设备负荷爬坡 | 与人员共用0.5h | 独立Type14，爬坡1.5h（9:00-10:30）| 9-11点峰值分散 |
| EXT_WINDOW1遮阳早晨阈值 | 关闭1180（328 W/m²） | 早晨7:00-10:00窗口改为800（222 W/m²） | 减少开机前蓄热 |

## 8. 小结

| 评估项 | 结论 |
|---|---|
| 稳态负荷指标 | ✅ 103.6 W/m²，完全符合上海研发办公楼标准 |
| 开机尖峰（8:15） | ⚠️ 3575 kW（186 W/m²），系理想冷源产物，实际设备不会如此极端；蓄冷系统放冷可平抑 |
| 9-22段峰/稳比 | ⚠️ 1.54，偏高；蓄冷场景目标<1.3，需通过会议室错峰+设备缓启动+斜坡控制来改善 |
| 峰谷差（午休谷/下午峰） | 约28%，有利于午休期间冷机回充水箱，日内蓄/放冷节奏清晰 |
| 核心削峰建议 | 优先级：制冷斜坡启动 > 会议室三组错峰 > 会议室峰值人数上限降至140 > 设备缓爬坡 |
